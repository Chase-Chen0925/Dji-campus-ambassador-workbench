# 大疆社媒审核工具

软件包含两个板块：

- **账号周更审核**：批量混合输入抖音、小红书主页链接，检测近 7 天是否发布作品，并展示 Tag、点赞数和是否超过 1000 赞。
- **投稿水印审核**：批量混合输入抖音、小红书、B站和微信视频号的单条作品链接，检查“设备话题 + 活动 Tag”以及互动量是否严格大于 200；产品水印由审核人员打开视频后手动勾选。

普通用户请下载对应系统的安装包，并阅读 [安装与使用教程](安装与使用教程.md)。安装版无需配置 Python 环境。

## 启动

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。

## 使用说明

1. 含抖音链接时，先打开抖音登录窗口并扫码；小红书登录是可选的，遇到登录限制再使用。
2. 从两个平台网页版复制账号主页链接，可混合粘贴，每行一个，单次最多 50 个。
3. 点击“开始批量检测”。程序会复用同一个登录会话逐个读取账号，并实时显示当前读取数量和进度条。读取期间可暂停/继续，或取消并保留已完成结果。
4. 若登录窗口不可用，也可以在高级区域填写已登录请求的 `Cookie` 请求头。
5. 检测完成后点击“导出 Excel”，下载包含以下四列的审核表：`本周是否有发作品`、`创作内容方向`、`是否有爆款`、`爆款来源`。其中爆款来源为超过 1000 赞作品的去重 Tag。

## 投稿水印审核

1. 点击顶部“投稿水印审核”。
2. 输入本次活动 Tag，一行一个、数量不限（例如 `#大疆校园暑期出片计划`）。作品命中其中任意一个活动 Tag 即通过该项。
3. 常用设备话题清单可按需修改；程序也会自动接受 `#大疆pocket4p`、`#大疆御4pro` 等“大疆 + 产品型号”话题，不要求必须命中默认清单。
4. 混合粘贴抖音、小红书、B站或微信视频号作品链接，每行一个，投稿审核不限制数量。小红书同时支持 `xhslink.cn`、`xhslink.com` 和完整作品链接。
5. 点击审核后可在进度条查看当前读取数量，也可暂停/继续，或取消并保留已完成结果。自动审核完成后，逐条打开作品确认产品水印（例如 `DJI OSMO POCKET 4`），再勾选“已打开视频并确认水印”。程序无法仅凭网页数据可靠识别视频画面水印。
6. 投稿链接按输入行保留，重复链接也会分别输出。Excel 包含平台、博主名字、博主 ID、原始作品链接、作品状态、投稿结果和读取说明；被删除的抖音作品会显示为“已删除”。

互动量计算规则：抖音/小红书为点赞 + 评论 + 收藏 + 分享；B站为点赞 + 投币 + 评论 + 收藏 + 分享；视频号为点赞 + 评论 + 爱心。只有总数 **严格大于 200** 才标记为优质作品。

投稿结论规则：设备话题和活动 Tag 同时通过即显示“满足投稿条件”；在此基础上互动量严格大于 200 显示“优质作品”。产品水印仍在独立列中人工确认。对于已删除的抖音作品，程序会锁定短链最初解析出的作品 ID，不采用页面自动跳转到其他视频后的数据。

投稿审核完成后可导出 Excel，包含平台、博主名字、博主 ID、作品链接、作品状态、`是否符合投稿要求`、`是否大于200互动量`和说明。已删除作品的作品状态及后两项审核结果均显示“已删除”。

手工输入的抖音 Cookie 仅随本次检测传给本机进程，不会写入磁盘。登录状态由 Chrome 分别保存在 `chrome-profile`、`xiaohongshu-chrome-profile` 和投稿读取专用目录中；请勿分享这些目录。

## 限制

各平台都会调整网页数据结构、接口签名和风控策略。本版优先读取公开页面，必要时使用真实 Chrome，不绕过验证码。出现风控时请在对应登录窗口中处理或稍后重试。检测不到互动数据时返回“待复核”，不会误判为未达标。
