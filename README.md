# 大疆社媒审核工具

软件包含两个板块：

- **账号周更审核**：批量混合输入抖音、小红书主页链接，检测近 7 天是否发布作品，并展示 Tag、点赞数和是否超过 1000 赞。
- **投稿水印审核**：批量混合输入抖音、小红书、B站和微信视频号的单条作品链接，检查“设备话题 + 活动 Tag”以及互动量是否严格大于 200；产品水印由审核人员打开视频后手动勾选。

普通用户请从 [`installers`](installers) 下载对应系统文件，并阅读 [安装包与安装说明](安装包与安装说明.md) 和 [安装与使用教程](安装与使用教程.md)。macOS 安装版无需配置 Python 环境；Windows 可通过 GitHub Actions 或附带的 BuildKit 生成 EXE 安装器。

## 启动

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。

## 使用说明

1. 含抖音链接时，先打开抖音登录窗口并扫码；小红书登录是可选的，遇到登录限制再使用。
2. 从两个平台网页版复制账号主页链接，可混合粘贴，每行一个，单次最多 50 个。
3. 点击“开始批量检测”。程序会复用同一个登录会话逐个读取账号，并实时显示当前读取数量和进度条。读取期间可暂停/继续，或取消并保留已完成结果。
4. 若登录窗口不可用，也可以在高级区域填写已登录请求的 `Cookie` 请求头。
5. 检测完成后点击“导出 Excel”，下载包含以下四列的审核表：`本周是否有发作品`、`创作内容方向`、`是否有爆款`、`爆款来源`。其中爆款来源为超过 1000 赞作品的去重 Tag。

# 大疆社媒审核工具｜安装与使用教程

## 一、准备条件

- macOS 11 或更高版本；或者 Windows 10/11 64 位。
- 已安装最新版 Google Chrome 或 Microsoft Edge。
- 能正常访问抖音、小红书、B站和微信视频号网页版。检测抖音需准备可登录的抖音账号；小红书登录为可选。
- 安装版不需要 Python、Node.js 或 Excel；导出的 `.xlsx` 可以用 Microsoft Excel、WPS 或 LibreOffice 打开。

## 二、macOS 安装

1. 双击 `抖音周更雷达-1.2.4-macOS-universal.dmg`。
2. 将“抖音周更雷达”拖到右侧的 `Applications` 文件夹。
3. 第一次启动时，在“应用程序”中右键“抖音周更雷达”，选择“打开”。
4. 如果系统仍然阻止启动，进入“系统设置 → 隐私与安全性”，找到相关提示并选择“仍要打开”。
5. 程序启动后会自动打开浏览器页面 `http://127.0.0.1:8765`。

说明：当前安装包使用本地临时签名，没有 Apple 公证，因此第一次打开可能出现安全提示。程序只在本机 `127.0.0.1` 上运行。

## 三、Windows 安装

1. 双击 `DouyinWeeklyRadar-1.2.4-Windows-Setup.exe`。
2. 按安装向导完成安装，可选择创建桌面快捷方式。
3. 如果 Microsoft Defender SmartScreen 出现提示，确认文件来源后点击“更多信息 → 仍要运行”。
4. 从桌面或开始菜单打开“抖音周更雷达”。
5. 程序会自动打开浏览器页面 `http://127.0.0.1:8765`。

## 四、第一次使用

1. 在网页的 `STEP 01` 点击“打开抖音登录窗口”。
2. 在弹出的专用 Chrome/Edge 窗口中扫码登录抖音。
3. 登录完成后回到周更雷达页面，点击“验证登录”。
4. 小红书登录是可选的。只检测公开主页时可直接点“进入批量检测”；如遇登录限制或风控，再打开小红书登录窗口。

专用浏览器登录状态只保存在本机：

- macOS：`~/Library/Application Support/DouyinWeeklyRadar/chrome-profile`
- Windows：`%APPDATA%\DouyinWeeklyRadar\chrome-profile`

小红书状态分别保存在同一目录下的 `xiaohongshu-chrome-profile`，不与抖音登录混用。

## 五、批量检测主页

1. 在输入框中粘贴抖音或小红书主页链接，两种链接可混合，每行一个，单次最多 50 个。
2. 点击“开始批量检测”。
3. 每个账号约需 20 秒，检测期间不要关闭专用登录窗口。需要暂时停下时点击“暂停”，之后可点击“继续”；点击“取消并保留结果”会在当前链接结束后停止，并保留已经完成的结果。
4. 结果会显示：近 7 天是否更新、新作品数量、千赞作品数量、作品 Tag、点赞数与作品链接。
5. “无法确认”与“无更新”含义不同：前者表示登录失效或平台风控，不能据此判断账号没有更新。小红书风控代码 `300012` 也会明确显示为“无法确认”。

## 六、导出 Excel

检测完成后点击“导出 Excel”。表格包含四列：

| 列名 | 含义 |
|---|---|
| 本周是否有发作品 | 近 7 天有作品填“是”，没有填“否” |
| 创作内容方向 | 近 7 天作品的去重 Tag；没有 Tag 时使用文案摘要 |
| 是否有爆款 | 只要有作品点赞数大于 1000，就填“是” |
| 爆款来源 | 所有爆款作品的 Tag，合并并去重 |

一行对应一个输入账号，顺序与输入链接顺序一致。

## 七、投稿水印审核

1. 点击页面顶部“投稿水印审核”。
2. 填写本次活动 Tag，一行一个、数量不限，例如 `#大疆校园暑期出片计划`。作品命中其中任意一个活动 Tag 即通过该项；活动变化时请人工增删。
3. 常用设备话题可以增删，一行一个；默认列出五个示例。程序也会自动识别 `#大疆pocket4p`、`#大疆御4pro` 等“大疆 + 产品型号”话题，无需事先加入清单。
4. 粘贴单条作品链接，每行一个，可混合输入抖音、小红书、B站、微信视频号，投稿审核不限制数量。小红书支持 `xhslink.cn`、`xhslink.com` 和完整作品链接。
5. 点击“开始投稿审核”。页面进度条会显示当前读取数量；读取期间可暂停/继续，或取消并保留已完成结果。程序会判断是否同时包含设备话题和任意一个活动 Tag，并计算互动量是否严格大于 200。
6. **必须逐条打开视频人工确认产品水印**，例如 `DJI OSMO POCKET 4`。确认后勾选表格里的“已打开视频并确认水印”；未勾选时综合结果保持“待人工确认水印”。

互动量公式：

| 平台 | 计算方式 |
|---|---|
| 抖音 | 分享 + 点赞 + 评论 + 收藏 |
| 小红书 | 分享 + 点赞 + 评论 + 收藏 |
| 微信视频号 | 点赞 + 评论 + 爱心 |
| B站 | 点赞 + 投币 + 评论 + 收藏 + 分享 |

等于 200 不通过，必须大于 200。若平台未公开某项数据或触发风控，结果显示“无法确认/待复核”，请打开原作品人工核实。

综合结果中，Tag 审核通过即显示“满足投稿条件”；Tag 通过且互动量大于 200 显示“优质作品”。水印继续在“产品水印（人工）”一列单独勾选。抖音原作品被删除后即使页面自动跳转，程序也不会读取跳转后的其他作品。

点击投稿结果右上角“导出 Excel”，将得到只含 `是否符合投稿要求`、`是否大于200互动量` 两列的表格，行顺序与投稿链接输入顺序一致。无法读取 Tag 或互动数时对应单元格填写“无法确认”。

## 八、退出和卸载

- 退出：点击网页底部的“退出程序”。只关闭网页标签不会停止后台程序。
- macOS 卸载：退出程序，将“应用程序”中的 App 移到废纸篓。若需清除登录状态，再删除 `~/Library/Application Support/DouyinWeeklyRadar`。
- Windows 卸载：进入“设置 → 应用 → 已安装的应用”，卸载“抖音周更雷达”。若需清除登录状态，再删除 `%APPDATA%\DouyinWeeklyRadar`。

## 九、常见问题

### 点击检测后显示“尚未登录”

回到专用 Chrome/Edge 窗口重新登录，再点击“验证登录并进入检测”。不要在普通浏览器窗口登录，因为两者使用不同的浏览器配置。

### 显示“服务异常”、“安全限制”或“无法确认”

平台可能触发了验证码或风控。检查对应的专用登录窗口，完成验证后重试；小红书显示 `300012` 时，请切换可靠网络或稍后重试。

### 小红书显示“读取失败 / 未登录”

小红书登录按钮是可选的，但小红书网站有时会强制主页访客登录。点击“打开小红书登录”，在专用 Chrome/Edge 中扫码，页面进入小红书首页后再点“验证登录”。新版会检查真实页面状态，不会再把过期 Cookie 误判为登录成功。

### 页面没有自动打开

在浏览器手动输入 `http://127.0.0.1:8765`。如果端口被占用，程序会依次尝试 `8766` 到 `8774`。

### 安装新版后还是旧页面

先在旧页面底部点击“退出程序”，再启动新版。页面顶部和底部会显示版本号，并会自动避开尚未退出的旧版后台。

### 找不到 Chrome 或 Edge

安装最新版 Google Chrome 或 Microsoft Edge，然后重新启动程序。

### Excel 中为什么没有账号列

导出格式严格使用指定的四列；每一行按照网页输入链接的先后顺序对应账号。

## 十、隐私说明

- 服务只监听本机地址 `127.0.0.1`，不会开放给局域网或公网。
- 手工输入的 Cookie 不写入磁盘。
- 扫码登录信息保存在本机专用浏览器目录，不会上传到本程序的服务器。
- 主页及投稿检测会直接访问对应平台网站，仍受登录、验证码、公开字段和风控策略影响。


## 投稿水印审核

1. 点击顶部“投稿水印审核”。
2. 输入本次活动 Tag，一行一个、数量不限（例如 `#大疆校园暑期出片计划`）。作品命中其中任意一个活动 Tag 即通过该项。
3. 常用设备话题清单可按需修改；程序也会自动接受 `#大疆pocket4p`、`#大疆御4pro` 等“大疆 + 产品型号”话题，不要求必须命中默认清单。
4. 混合粘贴抖音、小红书、B站或微信视频号作品链接，每行一个，投稿审核不限制数量。小红书同时支持 `xhslink.cn`、`xhslink.com` 和完整作品链接。
5. 点击审核后可在进度条查看当前读取数量，也可暂停/继续，或取消并保留已完成结果。自动审核完成后，逐条打开作品确认产品水印（例如 `DJI OSMO POCKET 4`），再勾选“已打开视频并确认水印”。程序无法仅凭网页数据可靠识别视频画面水印。

互动量计算规则：抖音/小红书为点赞 + 评论 + 收藏 + 分享；B站为点赞 + 投币 + 评论 + 收藏 + 分享；视频号为点赞 + 评论 + 爱心。只有总数 **严格大于 200** 才标记为优质作品。

投稿结论规则：设备话题和活动 Tag 同时通过即显示“满足投稿条件”；在此基础上互动量严格大于 200 显示“优质作品”。产品水印仍在独立列中人工确认。对于已删除的抖音作品，程序会锁定短链最初解析出的作品 ID，不采用页面自动跳转到其他视频后的数据。

投稿审核完成后可导出 Excel，严格包含两列：`是否符合投稿要求`、`是否大于200互动量`。

手工输入的抖音 Cookie 仅随本次检测传给本机进程，不会写入磁盘。登录状态由 Chrome 分别保存在 `chrome-profile`、`xiaohongshu-chrome-profile` 和投稿读取专用目录中；请勿分享这些目录。

## 限制

各平台都会调整网页数据结构、接口签名和风控策略。本版优先读取公开页面，必要时使用真实 Chrome，不绕过验证码。出现风控时请在对应登录窗口中处理或稍后重试。检测不到互动数据时返回“待复核”，不会误判为未达标。
