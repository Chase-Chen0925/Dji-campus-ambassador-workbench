# 大疆校园影像大使工作台 1.2.4：安装说明

安装文件位于仓库的 `installers` 文件夹。

## macOS 安装

文件：`installers/抖音周更雷达-1.2.4-macOS-universal.dmg`

1. 下载并双击 DMG 文件。
2. 把“抖音周更雷达”拖入“应用程序”文件夹。
3. 第一次启动时，如果 macOS 提示无法验证开发者，请在 Finder 的“应用程序”中右键应用，选择“打开”，再确认一次。
4. 程序启动后会自动打开本机网页。使用账号周更功能前先在程序提供的登录窗口完成平台登录。

该 DMG 同时支持 Apple 芯片和 Intel 芯片 Mac。

## Windows 安装

由于 Windows `.exe` 必须在 Windows 环境中构建，本仓库附带：

`installers/DouyinWeeklyRadar-1.2.4-Windows-BuildKit.zip`

### 方法一：通过 GitHub Actions 自动生成安装器（推荐）

1. 把本文件夹中的全部内容上传到 GitHub 仓库。
2. 打开仓库顶部的 `Actions`。
3. 选择 `Build macOS and Windows installers`。
4. 点击 `Run workflow`，等待任务完成。
5. 在完成的任务页面下载 `Windows-installer` 构建产物。
6. 解压后双击 `DouyinWeeklyRadar-1.2.4-Windows-Setup.exe`，按安装向导完成安装。

### 方法二：在 Windows 电脑本地生成安装器

1. 安装 Python 3，并勾选 `Add Python to PATH`。
2. 安装 Inno Setup 6。
3. 解压 `DouyinWeeklyRadar-1.2.4-Windows-BuildKit.zip`。
4. 双击其中的 `packaging/一键构建Windows安装包.bat`。
5. 构建完成后，在 `release` 文件夹找到 `DouyinWeeklyRadar-1.2.4-Windows-Setup.exe`。
6. 双击该 EXE，按安装向导完成安装。

Windows 使用前还需要安装 Google Chrome 或 Microsoft Edge。

## 使用提醒

- 登录状态只保存在使用者自己的电脑，不会提交到 GitHub。
- 产品水印仍需人工打开视频确认。
- 暂停或取消会在当前链接读取完成后生效；取消后已完成结果仍可导出。
- 不要把 `chrome-profile`、`xiaohongshu-chrome-profile`、`submission-chrome-profile` 或 `outputs` 文件夹上传到仓库。
