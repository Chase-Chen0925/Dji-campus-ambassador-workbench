# 大疆社媒审核工具｜安装与使用教程

## 一、准备条件

- macOS 11 或更高版本；或者 Windows 10/11 64 位。
- 已安装最新版 Google Chrome 或 Microsoft Edge。
- 能正常访问抖音、小红书、B站和微信视频号网页版。检测抖音需准备可登录的抖音账号；小红书登录为可选。
- 安装版不需要 Python、Node.js 或 Excel；导出的 `.xlsx` 可以用 Microsoft Excel、WPS 或 LibreOffice 打开。

## 二、macOS 安装

1. 双击 `DJI-campus-2.0.0-macOS-universal.dmg`（V-2.0）。
2. 将“DJI campus”拖到右侧的 `Applications` 文件夹。
3. 第一次启动时，在“应用程序”中右键“DJI campus”，选择“打开”。
4. 如果系统仍然阻止启动，进入“系统设置 → 隐私与安全性”，找到相关提示并选择“仍要打开”。
5. 程序启动后直接打开“大疆校园工作台”独立应用窗口，无需在浏览器打开主界面。

说明：当前安装包使用本地临时签名，没有 Apple 公证，因此第一次打开可能出现安全提示。程序只在本机 `127.0.0.1` 上运行。

## 三、Windows 安装

1. 双击 `DouyinWeeklyRadar-2.0.0-Windows-Setup.exe`（V-2.0）。
2. 按安装向导完成安装，可选择创建桌面快捷方式。
3. 如果 Microsoft Defender SmartScreen 出现提示，确认文件来源后点击“更多信息 → 仍要运行”。
4. 从桌面或开始菜单打开“DJI campus”。
5. 程序直接打开“大疆校园工作台”独立应用窗口。Windows 桌面显示使用 Microsoft Edge WebView2 运行时，系统未安装时需先安装微软官方运行时。

## 四、第一次使用

1. 在网页的 `STEP 01` 点击“打开抖音登录窗口”。
2. 在弹出的专用 Chrome/Edge 窗口中扫码登录抖音。
3. 登录完成后回到周更雷达页面，点击“验证登录”。
4. 小红书登录是可选的。只检测公开主页时可直接点“进入批量检测”；如遇登录限制或风控，再打开小红书登录窗口。

专用浏览器登录状态只保存在本机：

- macOS：`~/Library/Application Support/DouyinWeeklyRadar/chrome-profile`
- Windows：`%APPDATA%\DouyinWeeklyRadar\chrome-profile`

小红书状态分别保存在同一目录下的 `xiaohongshu-chrome-profile`，不与抖音登录混用。

## 五、批量检测主页

1. 在输入框中粘贴抖音或小红书主页链接，两种链接可混合，每行一个，单次最多 50 个。
2. 点击“开始批量检测”。
3. 每个账号约需 20 秒，检测期间不要关闭专用登录窗口。需要暂时停下时点击“暂停”，之后可点击“继续”；点击“取消并保留结果”会在当前链接结束后停止，并保留已经完成的结果。
4. 结果会显示：近 7 天是否更新、新作品数量、千赞作品数量、作品 Tag、点赞数与作品链接。
5. “无法确认”与“无更新”含义不同：前者表示登录失效或平台风控，不能据此判断账号没有更新。小红书风控代码 `300012` 也会明确显示为“无法确认”。

## 六、导出 Excel

检测完成后点击“导出 Excel”。表格包含四列：

| 列名 | 含义 |
|---|---|
| 本周是否有发作品 | 近 7 天有作品填“是”，没有填“否” |
| 创作内容方向 | 近 7 天作品的去重 Tag；没有 Tag 时使用文案摘要 |
| 是否有爆款 | 只要有作品点赞数大于 1000，就填“是” |
| 爆款来源 | 所有爆款作品的 Tag，合并并去重 |

一行对应一个输入账号，顺序与输入链接顺序一致。

## 七、投稿水印审核

1. 点击页面顶部“投稿水印审核”。
2. 填写本次活动 Tag，一行一个、数量不限，例如 `#大疆校园暑期出片计划`。作品命中其中任意一个活动 Tag 即通过该项；活动变化时请人工增删。
3. 常用设备话题可以增删，一行一个；默认列出五个示例。程序也会自动识别 `#大疆pocket4p`、`#大疆御4pro` 等“大疆 + 产品型号”话题，无需事先加入清单。
4. 粘贴单条作品链接，每行一个，可混合输入抖音、小红书、B站、微信视频号，投稿审核不限制数量。小红书支持 `xhslink.cn`、`xhslink.com` 和完整作品链接。
5. 点击“开始投稿审核”。页面进度条会显示当前读取数量；读取期间可暂停/继续，或取消并保留已完成结果。程序会判断是否同时包含设备话题和任意一个活动 Tag，并计算互动量是否严格大于 200。
6. **必须逐条打开视频人工确认产品水印**，例如 `DJI OSMO POCKET 4`。确认后勾选表格里的“已打开视频并确认水印”；未勾选时综合结果保持“待人工确认水印”。

互动量公式：

| 平台 | 计算方式 |
|---|---|
| 抖音 | 分享 + 点赞 + 评论 + 收藏 |
| 小红书 | 分享 + 点赞 + 评论 + 收藏 |
| 微信视频号 | 点赞 + 评论 + 爱心 |
| B站 | 点赞 + 投币 + 评论 + 收藏 + 分享 |

等于 200 不通过，必须大于 200。若平台未公开某项数据或触发风控，结果显示“无法确认/待复核”，请打开原作品人工核实。

综合结果中，Tag 审核通过即显示“满足投稿条件”；Tag 通过且互动量大于 200 显示“优质作品”。水印继续在“产品水印（人工）”一列单独勾选。抖音原作品被删除后即使页面自动跳转，程序也不会读取跳转后的其他作品。

投稿结果在“>200”右侧增加“>1万”检测，同时展示超过 1 万互动量的作品数量。使用上方同一总互动量公式，等于 10,000 不通过，严格大于 10,000 才显示“是”；数据未能读取时显示“待复核”。这不会改变月度有效投稿的计数条件。

点击投稿结果右上角“导出 Excel”，将得到包含平台、博主名字、博主 ID、作品链接、作品状态、`是否符合投稿要求`、`是否大于200互动量`、`是否大于1万互动量`和说明的表格，行顺序与投稿链接输入顺序一致。无法读取 Tag 或互动数时对应单元格填写“无法确认”；已删除作品的作品状态及三项审核结果均填写“已删除”。

## 设备流转

四款设备均配有随软件内置的型号图片，在设备库、空闲设备区和借用表单中显示。点击型号图片可以直接选中该设备；Pocket 4 使用去除旁侧配件的机身图。

1. 点击顶部“设备流转”，填写 pocket4、action6、nano、osmo360 各型号的总数量，点击“保存设备数量”。不参与流转的型号填写 0。每台设备自动编号，例如 pocket4-001。
2. 页面默认显示本月月历。点击某一天，查看当天安排，并将表单日期设为当天；使用左右箭头查看其他月份，“本月”返回今天。
3. 填写借用同学、设备型号、数量、开始与结束日期及可选备注，点击“保存流转安排”。同学可分多次借用不同型号。
4. 开始日、结束日都算占用日。例如 10月29日至10月31日的设备，11月1日可再次借出。跨月安排会在涉及的每一天显示。
5. “空闲设备”展示所选整个日期范围内均可借出的设备名称与数量。系统自动分配编号；数量不足或日期冲突时会拒绝保存并提示剩余数量。
6. 点击日历里的日期，在下方表格使用“修改”或“取消安排”。减少设备库数量前，需先处理被移除编号上的当前或未来安排。过往记录会保留。

安装版设备记录保存为 `device-flow.json`：macOS 位于 `~/Library/Application Support/DouyinWeeklyRadar/`，Windows 位于 `%APPDATA%\DouyinWeeklyRadar\`。退出程序后复制此文件可备份；重新安装或替换 App 不会清除该目录。源码运行时保存在源码目录。设备模块无需登录平台，可离线使用。

### 长期流转（V-2.0 新增）

填写同学、设备、数量和开始日期，勾选“长期流转，直到人工取消”后，结束日期自动隐藏，无需填写。保存后，该设备从开始日起持续占用，之后每个月、跨年和重启后均显示长期安排，不会自动到期。

长期安排会检查开始日之后所有已有预约；已有未来预约的设备不属于可长期流转的空闲设备。点击日历中的任意占用日期，可在下方记录表点击“取消长期流转”。取消后从当天释放，过去的流转历史保留；已取消的历史记录不能直接重新激活，如需再次流转请新建。也可通过“修改”将有效的长期安排手动改为有结束日期的普通安排。

## 月度投稿目标（1.5.0 新增）

1. 打开独立的“月度投稿目标”板块，默认查看本月，目标固定为每月 120 条。“查看月份”改为下拉选择，直接选择年月即可查看对应进度。已保存投稿记录的历史月份也会自动加入选项；点击“回到本月”可快速返回。
2. 在“投稿水印审核”完成审核后，打开原作品核对画面水印。设备 Tag、活动 Tag 和作品状态均通过时，勾选“已打开视频并确认水印”，该作品自动计入首次确认月份。
3. 同一作品依靠平台作品 ID 去重；重复链接、不同分享参数、短链与长链、再次审核或跨月再审都不会重复增加。无法获取唯一作品 ID 的结果暂不计入，以免误算。
4. 互动量超过 200 是“优质作品”指标，并非这 120 条有效投稿的额外门槛。
5. 误勾选时可以取消勾选，或在月度列表点击“撤销计入”。撤销后重新确认仍归入原月份，不会转移到新月份。
6. 数据保存在本机应用数据目录中的 `campus-submissions.sqlite3`。关闭窗口或升级软件后仍保留；换电脑不会自动同步，需要在退出软件后备份并迁移数据目录。升级前未保存的审核结果需要重新审核并确认后计入。

### 小红书投稿登录

投稿板块提供“打开小红书登录”按钮。程序复用同一专用浏览器页面和本机登录目录，扫描一次后连续审核。读取时请保留该专用窗口。若登录确实过期或平台要求验证码，进度栏会提示，程序会等待最多三分钟供你操作，完成后自动继续当前作品；超时后保留已完成结果并停止本轮，不逐条反复弹登录。请完成登录后只提交剩余未审核链接。

## 八、退出和卸载

- 退出：关闭软件窗口，或点击底部“退出程序”。本机设备记录不会被清除。开发用浏览器兼容模式仍需点击“退出程序”停止后台服务。
- macOS 卸载：退出程序，将“应用程序”中的 App 移到废纸篓。若需清除登录状态，再删除 `~/Library/Application Support/DouyinWeeklyRadar`。
- Windows 卸载：进入“设置 → 应用 → 已安装的应用”，卸载“DJI campus”。若需清除登录状态和记录，再删除 `%APPDATA%\DouyinWeeklyRadar`；旧版安装项可能仍显示为“抖音周更雷达”。

## 九、常见问题

### 点击检测后显示“尚未登录”

回到专用 Chrome/Edge 窗口重新登录，再点击“验证登录并进入检测”。不要在普通浏览器窗口登录，因为两者使用不同的浏览器配置。

### 显示“服务异常”、“安全限制”或“无法确认”

平台可能触发了验证码或风控。检查对应的专用登录窗口，完成验证后重试；小红书显示 `300012` 时，请切换可靠网络或稍后重试。

### 小红书显示“读取失败 / 未登录”

小红书登录按钮是可选的，但小红书网站有时会强制主页访客登录。点击“打开小红书登录”，在专用 Chrome/Edge 中扫码，页面进入小红书首页后再点“验证登录”。新版会检查真实页面状态，不会再把过期 Cookie 误判为登录成功。

### 页面没有自动打开

请重新启动软件；主界面应直接显示在独立应用窗口。若弹出缺少组件的提示，请重新安装完整安装包。源码调试时可执行 `python app.py --browser` 使用浏览器兼容模式；默认本地端口为 8765，占用时会尝试后续端口。

### 安装新版后还是旧页面

先在旧页面底部点击“退出程序”，再启动新版。页面顶部和底部会显示版本号，并会自动避开尚未退出的旧版后台。

### 找不到 Chrome 或 Edge

安装最新版 Google Chrome 或 Microsoft Edge，然后重新启动程序。

### Excel 中为什么没有账号列

导出格式严格使用指定的四列；每一行按照网页输入链接的先后顺序对应账号。

## 十、隐私说明

- 服务只监听本机地址 `127.0.0.1`，不会开放给局域网或公网。
- 手工输入的 Cookie 不写入磁盘。
- 扫码登录信息保存在本机专用浏览器目录，不会上传到本程序的服务器。
- 主页及投稿检测会直接访问对应平台网站，仍受登录、验证码、公开字段和风控策略影响。
