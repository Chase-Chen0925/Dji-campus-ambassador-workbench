# 开发者构建教程

## macOS

在 macOS 终端进入项目目录后执行：

```bash
bash packaging/build_macos.sh
```

脚本会创建独立构建环境、安装依赖、生成 universal2 App、执行临时签名并输出：

```text
release/DJI-campus-2.0.0-macOS-universal.dmg
```

若要公开分发且不显示 Gatekeeper 警告，需要使用 Apple Developer ID 证书签名并提交 Apple 公证。本项目的默认脚本只做 ad-hoc 签名。

## Windows

先安装：

- Python 3.10 或更高版本（勾选 Add Python to PATH）
- Inno Setup 6

在 PowerShell 中进入项目目录后执行：

```powershell
.\packaging\build_windows.ps1
```

输出文件：

```text
release\DouyinWeeklyRadar-2.0.0-Windows-Setup.exe
```

若要避免 SmartScreen 警告，需要使用受信任的 Windows Code Signing 证书签名安装包。

## GitHub Actions 自动构建

将项目推送到 GitHub 后，在 Actions 页面手动运行 `Build macOS and Windows installers`，或者创建 `v*` 标签。工作流会分别在 macOS 和 Windows 运行器中构建，并上传两个安装包作为 Artifacts。
