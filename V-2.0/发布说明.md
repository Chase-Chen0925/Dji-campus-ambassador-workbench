# DJI campus V-2.0

内部版本号：2.0.0。

## 安装包

安装包位于“安装包”目录。macOS 包支持 Apple 芯片和 Intel；Windows 安装包需要通过 Windows 本机或 GitHub Actions 构建。

本次导出文件：`DJI-campus-2.0.0-macOS-universal.dmg`

SHA-256：`b1325625fec443359bea9b99377564837454811a2f54fc2dd03e6a5ce247f7f7`

## 上传 GitHub

将“GitHub上传”文件夹内的全部内容放到仓库根目录，包括隐藏的 `.github` 和 `.gitignore`。该目录包含与安装包对应的源码、测试、图片、图标、依赖及构建配置，不含登录信息和本机业务数据。在 GitHub Actions 中运行 Build macOS and Windows installers，可构建对应平台安装包。后续通过打包脚本构建时，也会自动同步导出对应源码。

## 本版功能

- 设备长期流转：勾选后无结束日期，之后每个月持续保留，人工取消当天释放，过去记录保留。
- 月度目标的查看月份采用下拉选择，并保留有投稿记录的历史月份。
- 投稿水印审核在大于 200 的右侧新增大于 1 万的检测，统计卡片与 Excel 导出同步显示；严格大于 10,000 才通过。
- 保留投稿审核、作品去重统计、月度 120 条目标、小红书会话复用和设备图片等已有功能。

升级前请退出旧版。软件沿用原有本机数据目录，升级不会清除已有设备和月度记录。
